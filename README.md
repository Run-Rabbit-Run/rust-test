# Первая игра на Bevy

Мини-игра для старта: синий квадрат двигается по полю, собирает жёлтые цели и побеждает после 5 попаданий.

Управление:
- `WASD` или стрелки: движение
- `R`: начать заново

Что здесь полезно разбирать для изучения Rust и Bevy:
- `main`: как создаётся приложение и подключаются системы
- `Component`: как описывать данные сущностей
- `Resource`: как хранить общее состояние игры
- `Query`: как получать доступ к сущностям внутри систем
- `fn` и `const`: как организовывать код в маленькие понятные блоки

Запуск:

```bash
cargo run
```
