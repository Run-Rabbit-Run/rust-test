# Глава 8. Общие коллекции: практические задания

Цель этих заданий - закрепить работу с тремя основными коллекциями из главы 8: `Vec<T>`, `String` и `HashMap<K, V>`.

Решения можно писать в `src/main.rs` или создавать отдельные функции и вызывать их из `main`. После каждого задания запускай:

```bash
cargo run
```

## Задание 1. Температуры за неделю

### Краткая теория

`Vec<T>` хранит несколько значений одного типа в памяти рядом друг с другом. Вектор можно создать через `Vec::new()` или макрос `vec![]`. Чтобы добавить элемент, используется `push`. Для чтения элементов можно использовать индекс `temperatures[0]` или безопасный метод `get`, который возвращает `Option<&T>`.

### Что нужно сделать

Создай вектор температур за 7 дней, например `vec![18, 20, 21, 19, 17, 22, 23]`.

Выведи:

- все температуры через цикл `for`;
- первую температуру безопасно через `get`;
- среднюю температуру за неделю;
- максимальную и минимальную температуру.

Дополнительно: если вектор пустой, программа не должна паниковать.

## Задание 2. Список покупок

### Краткая теория

Вектор должен быть изменяемым, если ты хочешь добавлять или удалять элементы: `let mut items = Vec::new();`. Метод `push` добавляет элемент в конец. Метод `pop` удаляет последний элемент и возвращает `Option<T>`, потому что вектор может быть пустым.

### Что нужно сделать

Создай изменяемый вектор строк со списком покупок.

Программа должна:

- добавить минимум 5 товаров;
- вывести весь список с номерами, начиная с 1;
- удалить последний товар через `pop`;
- вывести удаленный товар или сообщение, что список был пуст;
- снова вывести итоговый список.

Подсказка: для строк можно использовать `String::from("milk")` или `"milk".to_string()`.

## Задание 3. Статистика чисел

### Краткая теория

Вектор удобно перебирать через `for value in &values`, если нужно только читать данные. Амперсанд означает заимствование: вектор остается доступен после цикла. Чтобы изменить каждый элемент, можно использовать `for value in &mut values`.

### Что нужно сделать

Создай функцию `analyze_numbers(numbers: &Vec<i32>)`, которая выводит:

- количество чисел;
- сумму;
- среднее значение;
- сколько чисел больше среднего.

Затем создай изменяемый вектор чисел и увеличь каждое число на 10 через цикл по `&mut`.

Проверь функцию до и после изменения вектора.

## Задание 4. Конструктор строки

### Краткая теория

`String` - изменяемая строка в куче, а строковый литерал вроде `"hello"` имеет тип `&str`. Чтобы менять строку, объяви ее как `mut`. Для добавления текста используются `push_str` и `push`. Метод `push_str` принимает строковый срез `&str`, а `push` добавляет один символ `char`.

### Что нужно сделать

Создай программу, которая собирает строку приветствия по частям.

Требования:

- начни с `String::from("Привет")`;
- добавь запятую через `push`;
- добавь пробел и имя через `push_str`;
- добавь восклицательный знак через `push`;
- выведи итоговую строку и ее длину через `len`.

После этого объясни в комментарии в коде, почему `len` для строки с русскими буквами не равен количеству видимых символов.

## Задание 5. Работа с UTF-8

### Краткая теория

Строки Rust хранятся в UTF-8. Из-за этого индексирование строки вроде `text[0]` запрещено: один видимый символ может занимать больше одного байта. Для посимвольного обхода используй `chars()`, а для обхода байтов - `bytes()`.

### Что нужно сделать

Создай строку:

```rust
let text = String::from("Здравствуйте");
```

Выведи:

- длину строки в байтах через `len`;
- каждый символ через `chars`;
- каждый байт через `bytes`;
- количество символов через `text.chars().count()`.

Дополнительно: попробуй временно написать `text[0]`, посмотри ошибку компилятора, затем убери этот код.

## Задание 6. Нормализация текста

### Краткая теория

Метод `split_whitespace` разбивает строку по пробельным символам и возвращает итератор по `&str`. Из частей можно собрать новую строку. Для добавления пробелов между словами удобно проверять, пустая ли результирующая строка.

### Что нужно сделать

Напиши функцию `normalize_spaces(text: &str) -> String`.

Она должна:

- убрать лишние пробелы между словами;
- убрать пробелы в начале и конце;
- сохранить сами слова без изменений.

Пример:

```text
"  Rust   любит   точность  " -> "Rust любит точность"
```

Не используй готовый метод `replace` для всей задачи. Сделай решение через `split_whitespace`, цикл и `String`.

## Задание 7. Таблица очков команд

### Краткая теория

`HashMap<K, V>` хранит пары ключ-значение. Для использования нужно подключить тип: `use std::collections::HashMap;`. Метод `insert` добавляет пару или заменяет старое значение для существующего ключа. Метод `get` возвращает `Option<&V>`, потому что ключа может не быть.

### Что нужно сделать

Создай `HashMap<String, i32>` с очками команд.

Программа должна:

- добавить минимум 3 команды;
- вывести все пары ключ-значение через цикл `for`;
- найти очки одной существующей команды через `get`;
- попробовать найти команду, которой нет в таблице;
- для отсутствующей команды вывести `0`, используя `copied().unwrap_or(0)`.

Помни: порядок вывода элементов `HashMap` не гарантирован.

## Задание 8. Регистрация пользователей

### Краткая теория

Если вызвать `insert` с уже существующим ключом, старое значение будет перезаписано. Если нужно вставить значение только при отсутствии ключа, используй `entry(key).or_insert(value)`. Метод `or_insert` возвращает изменяемую ссылку на значение внутри `HashMap`.

### Что нужно сделать

Создай `HashMap<String, String>`, где ключ - логин пользователя, значение - email.

Реализуй сценарий:

- добавь пользователя `alice`;
- попробуй добавить `alice` повторно через `insert` с другим email и покажи, что значение изменилось;
- добавь пользователя `bob` через `entry(...).or_insert(...)`;
- попробуй добавить `bob` повторно через `entry(...).or_insert(...)` с другим email и покажи, что значение не изменилось.

В конце выведи всю таблицу пользователей.

## Задание 9. Подсчет слов

### Краткая теория

Частый сценарий для `HashMap` - подсчет количества элементов. Метод `entry(word).or_insert(0)` возвращает изменяемую ссылку на счетчик. Чтобы увеличить значение по ссылке, нужно разыменование: `*count += 1`.

### Что нужно сделать

Напиши функцию `count_words(text: &str) -> HashMap<String, i32>`.

Она должна:

- разбить текст на слова через `split_whitespace`;
- привести каждое слово к нижнему регистру через `to_lowercase`;
- посчитать количество повторений каждого слова;
- вернуть `HashMap<String, i32>`.

Проверь на тексте:

```text
"Rust rust ownership borrowing Rust"
```

Ожидаемый результат по смыслу:

```text
rust -> 3
ownership -> 1
borrowing -> 1
```

Порядок вывода может отличаться.

## Задание 10. Итоговая задача: мини-анализатор текста

### Краткая теория

Коллекции часто используются вместе: `String` хранит входной текст, `Vec<T>` подходит для списка обработанных элементов, а `HashMap<K, V>` удобен для быстрых подсчетов по ключу. При передаче коллекций в функции чаще всего используют ссылки, чтобы не передавать владение без необходимости.

### Что нужно сделать

Напиши программу, которая анализирует текст:

```rust
let text = String::from("Rust makes systems programming accessible. Rust makes safety practical.");
```

Программа должна:

- сохранить все слова в `Vec<String>`;
- привести слова к нижнему регистру;
- убрать простую пунктуацию в конце слов: `.`, `,`, `!`, `?`;
- вывести количество слов;
- вывести самое длинное слово;
- построить `HashMap<String, i32>` с частотой слов;
- вывести частоты слов.

Ограничение: решай средствами из главы 8. Не используй регулярные выражения и внешние crate.

Дополнительно:

- оформи подсчет слов в отдельную функцию;
- оформи поиск самого длинного слова в отдельную функцию;
- добавь еще один текст для проверки.
